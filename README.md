# Мессенджер

Браузерный мессенджер на Node.js и чистом JS: вход по уникальному коду, переписка один на один, передача файлов, список чатов. Сообщения приходят сразу, по собственной реализации WebSocket.

## Запуск

Нужен только Node.js 22 или новее. `npm install` не нужен: зависимостей нет.

```
npm start
npm test
```

После `npm start` откройте http://127.0.0.1:3000.

Чтобы переписываться с собой, нужны две отдельные сессии: два разных браузера, приватное окно или адреса `http://localhost:3000` и `http://127.0.0.1:3000` в одном браузере (у них разные cookie).

## Настройки

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `PORT` | `3000` | порт сервера |
| `HOST` | `127.0.0.1` | адрес сервера, `0.0.0.0` откроет его для всей сети |
| `DATA_DIR` | `data` | папка с данными и файлами |

## Как пользоваться

1. Нажмите «Получить код», введите имя и сохраните код: он показывается один раз.
2. Передайте собеседнику свой ID, он показан над списком чатов.
3. Введите ID собеседника в поле «Новый чат» и пишите.

Enter отправляет сообщение, Shift и Enter начинают новую строку. Кнопка «Файл» прикрепляет файл до 10 МБ к строке ввода: к нему можно написать подпись, и уйдут они одним сообщением.

## Устройство

План, архитектура и API описаны в [PLAN.md](PLAN.md). Коротко:

- `server/` работает на стандартной библиотеке Node.js: `http`, `crypto`, `fs`. Сервисы не знают про транспорт, данные хранятся за репозиториями.
- `public/` это нативные ES-модули без сборки.
- `test/` запускает настоящий сервер на случайном порту во временной папке.

Сторонних зависимостей нет: для такого объёма хватает стандартной библиотеки, а нужная часть WebSocket по RFC 6455 занимает несколько сотен строк.

## Что не потеряется

- Сообщение подтверждается отправителю только после записи на диск.
- Если связь оборвалась, сообщение ждёт в очереди и уходит само. Сервер распознаёт повтор, поэтому дублей не будет.
- Если браузер не сообщает об обрыве, клиент замечает его сам, обычно за 35 секунд, и показывает это на экране.
- После каждого подключения открытый чат и список чатов догружаются сами.

## Ограничения

- Нет HTTPS: это задача reverse-proxy перед сервером. Пока его нет, cookie сессии идёт без флага `Secure`, поэтому в открытую сеть сервер так выставлять нельзя.
- Утерянный код нельзя восстановить, придётся зарегистрироваться заново.
- Один процесс без масштабирования, данные лежат в JSON-файлах. Новое сообщение переписывает файл целиком, это рассчитано на небольшой объём.
- Нет квот на суммарный объём файлов и на частоту сообщений.
- Сообщения в очереди живут до закрытия вкладки. Если они есть, браузер предупредит перед уходом со страницы.
