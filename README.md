# Мессенджер

Простой мессенджер в браузере: заходишь по коду, пишешь собеседнику по его ID, отправляешь файлы. Сервер на Node.js без единой зависимости, WebSocket написан свой.

## Запуск

Нужен Node.js 22+ (на Arch: `sudo pacman -S nodejs npm`). `npm install` не нужен.

```
npm start
npm test
```

Дальше открываете http://127.0.0.1:3000. Чтобы написать самому себе, нужна вторая сессия: другой браузер, приватное окно или адрес `http://localhost:3000`.

## Как пользоваться

1. «Получить код», ввести имя и сохранить код: он показывается один раз.
2. Отправить собеседнику свой ID, он над списком чатов.
3. Вписать его ID в «Новый чат» и писать.

Enter отправляет, Shift+Enter переносит строку. К сообщению можно приложить файл до 10 МБ.

## Настройки

`PORT` (3000), `HOST` (127.0.0.1), `DATA_DIR` (`data`) и `TRUST_PROXY` (0, поставьте 1 за HTTPS-прокси).

## HTTPS

HTTPS даёт прокси перед сервером. Проще всего Caddy:

```
example.com {
  header Strict-Transport-Security "max-age=31536000"
  reverse_proxy 127.0.0.1:3000
}
```

Сам сервер тогда запускается с `TRUST_PROXY=1 npm start`, а `HOST` остаётся `127.0.0.1`, чтобы в обход прокси к нему не попасть. Для nginx готовый конфиг лежит в [nginx.example.conf](nginx.example.conf).

## Что стоит знать

- Сообщения не теряются: при обрыве они ждут и уходят сами, без дублей.
- Без HTTPS в открытую сеть сервер выставлять нельзя. Сквозного шифрования нет, на сервере всё хранится как есть.
- Потерянный код не восстановить.
- Данные лежат в JSON-файлах, это рассчитано на небольшой объём.
