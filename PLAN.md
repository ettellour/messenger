План по мессенджеру

5 ноября

Решил делать обычный веб-мессенджер. Будет страница в браузере и сервер на Node.js. Из основного - вход по коду, личные чаты, отправка сообщений и файлов. Ничего лишнего добавлять пока не планирую, в задании этого и не было  .

1)Использую Node.js 22. На сервере стандартные модули http, crypto и fs. Express ставить не буду, маршрутов немного, проще написать свой небольшой роутер.

Клиентская часть будет на обычном JavaScript, без React и сборщиков. Интерфейс небольшой, поэтому отдельный фреймворк незачем.

С вебсокетами пока вопрос открытый. Сначала попробую написать собственную реализацию, если возникнут проблемы или это займёт слишком много времени, перейду на ws. 

2)Серверную часть разделю по классам:

Server и Router-HTTP-запросы и отдача статики.
 WebSocketServer-подключения пользователей и их статус.
AuthService-регистрация, коды и сессии.
ChatService-чаты и сообщения-работа с файлами.

3)Для хранения пока использую JSON в папке data. Отдельную базу данных на этом этапе подключать не планирую.

На клиенте будут ApiClient и SocketClient. Последний будет отвечать за подключение к серверу.

Сообщения передаются через сокет и сохраняются на сервере. Если собеседник в сети , получит сообщение сразу. Если нет, то оно останется в истории и будет доступно при следующем входе.

Сессия хранится в cookie. При подключении через WebSocket сервер проверяет ту же cookie.

4)Пока нужны четыре основных типа данных:

- User -id, хеш кода, имя.
- Chat  id, два участника, информация о прочитанных сообщениях.
- Message  id, чат, отправитель, текст или файл, время.
- File id, кто загрузил, имя и размер.

4)Пользователи будут добавлять друг друга по ID. Свой ID можно будет посмотреть в интерфейсе и скопировать. Общего списка пользователей не будет.

Непрочитанные сообщения считаются относительно последнего прочитанного сообщения в конкретном чате.

5)(API)

Через HTTP будут работать регистрация, вход и выход, список чатов, создание чата и загрузка истории.

Отправка сообщений, уведомления о новых сообщениях и отметки о прочтении будут  через WebSocket.

Файлы загружаются отдельно. После загрузки в чат отправляется обычное сообщение со ссылкой на файл, чтобы не передавать сами файлы через сокет.


6)Для cookie использую httpOnly и SameSite. Сообщения в интерфейсе будут выводиться через textContent, чтобы избежать XSS.

На входе бкдет ограничение  попыток, чтобы нельзя было перебирать коды. Файлы  на скачивание, а не открываться прямо в браузере.

7)HTTPS отдельно настраивается через nginx или прокси.

1. Подготовить структуру проекта, сервер и роутер. Сделать регистрацию и вход, проверить всё тестами.
2. Заняться WebSocket-соединениями и решить, оставлять собственную реализацию или использовать ws.
3. Добавить сообщения, сохранение истории и само окно переписки. Проверить отправку между двумя пользователями.
4. Сделать список чатов, создание новых переписок и непрочитанные сообщения.
5. Добавить загрузку и скачивание файлов.
6. Проверить переподключение, пройтись по основным сценариям, подготовить README.


8)Для запуска нужен Node.js 22.

Используются команды npm start и npm test. Порт и папку с данными можно менять через PORT и DATA_DIR.
